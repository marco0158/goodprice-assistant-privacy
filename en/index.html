We take user data security seriously. This policy explains how the extension processes, uses, stores, and shares the data necessary to help operations personnel verify product prices, organize promotional information, manage tasks, and publish deal submissions. Except for providing features explicitly used by the user, protecting service security, and collecting the usage statistics disclosed in this policy, we do not use data for other purposes.

1. Scope

This policy applies to GoodPrice Assistant (formerly SMZDM Deal Submission Assistant) when it runs in Chromium-based browsers such as Google Chrome and Microsoft Edge. The extension is maintained by an individual developer as an operations productivity tool for authorized internal company personnel; it is not offered as a service to general consumers.

This policy covers only the extension’s own data-processing practices. Data processing by websites and services such as JD.com, Tmall, Lark, SMZDM, and Google Analytics is also governed by their respective privacy policies.

2. Data We Process

Category Data How It Is Processed
Data provided by the user Product links, final prices, retailers, promotion details, submitter information, categories, tags, selected products, and spreadsheet fields imported by the user. Used to create, review, edit, and publish deal-submission tasks.
Web content and browsing activity When the user invokes a feature, the extension may read product URLs, SKUs, product names, prices, coupons, store details, campaign information, page state, and necessary deal-submission fields from supported pages. Processed only on supported websites while the user is using a relevant feature, for product identification, price verification, filtering, and form autofill.
Clipboard content After the user clicks an explicit entry point such as “Create Task from Clipboard,” the extension reads clipboard text and extracts HTTP/HTTPS product links. Clipboard access is optional. The extension does not continuously read the clipboard when the user has not invoked this feature.
Authentication and configuration data Internal business API keys configured or obtained by the user through an authorization flow, their validity status, and settings required for publishing, such as the default submitter. Primarily stored in the browser and used only to authenticate requests to the corresponding internal services; not used for advertising.
Local tasks and preferences Extension preferences, monitoring settings, task progress, success or failure results, published links, and recent task history. Stored locally in the browser to restore tasks, display history, and retain user settings.
Images, videos, and AI-processed content When the user enables gift parsing or media-processing features, the extension may process product-image URLs, user-selected images or videos, article identifiers, titles, and processing instructions. Sent only to internal business services necessary to provide the requested feature and return gift text or media-processing results.
Usage and diagnostic data A randomly generated client identifier, session identifier, extension version, features used, platform or domain, task counts, success or failure status, error type, and certain business-object identifiers. Basic usage events may be sent automatically when the extension is opened or a related feature is used, for feature analytics and stability analysis.

The extension does not intentionally collect government identification numbers, bank-card information, health information, or cross-site behavioral profiles for personalized advertising. It also does not read or store users’ passwords for third-party websites.

3. Purposes of Processing

We use the data described above only to:

  • identify products and campaign information, retrieve price history, and evaluate low-price status;
  • create, review, edit, and publish deal-submission tasks initiated by the user;
  • provide user-visible features such as shopping-cart monitoring, campaign-page filtering, search-results filtering, and coupon-bundle selection;
  • perform gift parsing and image or video processing according to the user’s settings;
  • save settings, restore task progress, and display local task history;
  • measure feature usage, troubleshoot failures, and improve stability within the scope disclosed in this policy; and
  • protect internal services, accounts, and the extension against abuse or security threats.

4. Storage and Retention

Local browser storage

The extension uses chrome.storage.local to store settings, API keys, task state, recent task history, and a random analytics identifier. This data is stored in the user’s browser profile and is not automatically deleted when a page is closed. Users may delete local data using the extension’s clearing controls, browser extension-data management features, or by uninstalling the extension.

Server-side processing

Data submitted to internal business services for price lookup, publishing, gift parsing, or media processing is retained only for as long as necessary to provide the feature, protect security, and meet internal audit requirements. After that period, data is deleted, anonymized, or overwritten according to the relevant business system’s data-governance rules.

Usage analytics

The random analytics client identifier remains in the browser until the user clears the extension’s data or uninstalls the extension. Usage statistics sent to Google Analytics are retained according to the Google Analytics property settings and the Google Privacy Policy. Analytics data is not used for personalized advertising.

5. Sharing and Third-Party Services

We do not sell user data, provide it to data brokers, or use it for personalized advertising. Data is transmitted only when necessary in the following circumstances:

Recipient Data That May Be Received Purpose
Relevant SMZDM internal business services Product links, SKU/Wiki IDs, prices, publishing fields, API keys, and image or media-processing requests. Authentication, price lookup, historical-price evaluation, deal publishing, gift parsing, and media processing.
Supported websites visited by the user Data submitted or operated on by the user on the corresponding website. Opening product pages, completing forms, and performing publishing actions initiated by the user.
Google Analytics Random client and session identifiers, version, feature events, platform/domain, result status, and similar usage data. Internal feature measurement, troubleshooting, and stability improvement. This processing is also governed by the Google Privacy Policy.

Outside the circumstances described above, we disclose data only when required by law, necessary to protect users or system security, or following a change in the service operator after obtaining any legally required consent.

6. Browser Permissions

  • storage: Saves settings, task progress, task history, and authorization configuration.
  • tabs / activeTab / scripting: Identifies, opens, or operates supported product and deal-submission pages when the user invokes a feature.
  • alarms: Supports task timeouts, polling, and shopping-cart monitoring schedules.
  • sidePanel: Displays task status and auxiliary controls.
  • system.display: Positions extension operation windows appropriately in multi-display environments.
  • clipboardRead (optional): Reads clipboard content and extracts links only after the user clicks a clipboard-import feature.
  • Host permissions: Runs user-visible features on JD.com, Tmall, SMZDM, Lark, and service domains that provide necessary internal capabilities.

7. User Choices, Access, and Deletion

  • Users may decline the optional clipboard-read permission and paste links manually instead.
  • Users who do not want new usage statistics to be generated may disable or uninstall the extension, or contact us using the email address below.
  • Users may clear task history and related local data, or uninstall the extension and remove its data through the browser.
  • To request access to, correction of, or deletion of data that may be retained by internal business services, contact us using the details below.

8. Data Security

We use reasonable technical and organizational measures to protect data, including limiting extension permissions, restricting access to internal services, requiring authentication, controlling retention, and continually improving data-transport security. Users should safeguard their API keys and must not share them with unauthorized individuals.

9. Chrome Web Store Limited Use Commitment

The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.

Specifically, we use relevant data only to provide or improve the extension’s clearly disclosed single purpose. We do not use the data for personalized advertising, sell it to third parties, or permit humans to read user data unless the user has given explicit consent for specific data, access is necessary for a security investigation, access is required by law, or the data has been aggregated and anonymized and is used only for compliant internal operations.

10. Policy Updates

We may update this policy when the extension’s features, data-processing practices, or applicable requirements change. The effective date at the top of this page will be updated accordingly. If a change materially affects the processing of user data, we will provide a prominent notice through the extension before collecting or using the affected data and will obtain renewed consent where required.
