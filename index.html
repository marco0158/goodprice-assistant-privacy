我们重视用户数据安全。本政策说明本扩展在帮助运营人员核验商品价格、整理优惠信息、管理任务并发布爆料时，如何处理、使用、保存和共享必要数据。除完成用户明确使用的功能、保障服务安全及本政策披露的使用统计外，我们不会将数据用于其他目的。

一、适用范围

本政策适用于 Chrome、Microsoft Edge 等 Chromium 浏览器中运行的“值得买好价运营助手”（原“值得买爆料助手”）。本扩展由个人开发者维护，是面向公司内部授权人员的运营效率工具，不面向普通消费者提供服务。

本政策仅适用于扩展自身的数据处理行为。京东、天猫、飞书、什么值得买、Google Analytics 等网站或服务对数据的处理，还受其各自隐私政策约束。

二、我们处理的数据

数据类别 具体内容 处理方式
用户主动提供的数据 商品链接、到手价、商城、优惠内容、爆料人、分类、标签、用户选择的商品，以及用户导入的表格字段。 用于创建、检查、编辑和发布爆料任务。
网页内容与浏览活动 用户使用功能时，扩展会读取受支持页面中的商品 URL、SKU、商品名称、价格、优惠券、店铺、活动信息、页面状态及必要的爆料页面字段。 仅在支持的网站和用户使用相关功能时处理，用于商品识别、价格核验、筛选和页面自动填写。
剪贴板内容 用户点击“从剪贴板创建任务”等明确入口后，扩展读取剪贴板文本并提取其中的 HTTP/HTTPS 商品链接。 剪贴板读取属于可选权限，不会在用户未触发该功能时持续读取剪贴板。
身份验证与配置数据 用户配置或通过授权流程取得的内部业务 API Key、Superset 登录会话 Cookie、有效状态，以及发布所需的默认爆料人等设置。 保存在浏览器的扩展存储或 Cookie 存储中，仅在调用相应内部服务时用于鉴权，不用于广告。
本地任务与偏好 扩展偏好、监控设置、任务进度、成功/失败结果、已发布链接和近期任务历史。 保存在浏览器本地，用于恢复任务、显示历史和保持用户配置。
图片、视频及 AI 处理内容 用户启用赠品解析或媒体处理功能时，可能处理商品图片地址、用户选择的图片/视频、文章标识、标题和处理指令。 仅发送至提供该功能所必需的内部业务服务，用于返回赠品文本或媒体处理结果。
使用情况与诊断数据 随机生成的客户端标识、会话标识、扩展版本、使用的功能、平台或域名、任务数量、成功/失败状态、错误类型，以及部分业务对象标识。 扩展打开或相关功能被使用时，可能自动发送基础使用事件，用于功能统计和稳定性分析。

我们不会通过扩展主动收集用户的身份证号码、银行卡信息、健康信息或用于个性化广告的跨网站行为档案。扩展也不会读取或保存用户在第三方网站上的登录密码。

三、数据使用目的

我们仅将上述数据用于：

  • 识别商品和活动信息，查询价格历史并进行低价判断；
  • 创建、检查、编辑和发布用户主动发起的爆料任务；
  • 执行购物车监控、活动页筛选、搜索页筛选和优惠券凑单等用户可见功能；
  • 根据用户设置进行赠品解析、图片或视频处理；
  • 保存设置、恢复任务进度、展示本地任务历史；
  • 按照本政策披露的范围统计功能使用情况、排查故障并改善稳定性；
  • 保护内部服务、账号和扩展免受滥用或安全威胁。

四、数据存储与保留

浏览器本地存储

扩展使用 chrome.storage.local 保存设置、API Key、任务状态、近期任务历史和随机统计标识。这些数据存储在用户浏览器配置目录中，不会因为关闭页面而自动清除。用户可以通过扩展提供的清理入口、浏览器扩展数据管理功能或卸载扩展删除本地数据。

Superset 登录会话 Cookie 保存在浏览器 Cookie 存储中，扩展仅对对应的内部 Superset 服务使用和管理该会话，以维持登录状态并完成用户启用的查询功能。

服务端处理

为完成价格查询、发布、赠品解析或媒体处理而提交到内部业务服务的数据，仅在提供功能、保障安全和满足内部审计要求所需的期限内保留。超过必要期限后，将根据相关业务系统的数据治理规则删除、匿名化或覆盖。

使用统计

随机统计客户端标识保存在浏览器本地，直至用户清除扩展数据或卸载扩展。发送至 Google Analytics 的使用统计按照 Google Analytics 后台设置及 Google 隐私权政策保留。统计数据不会被用于个性化广告。

五、数据共享与第三方服务

我们不会出售用户数据，也不会将用户数据提供给数据经纪商或用于个性化广告。仅在以下必要情形传输数据：

接收方 可能接收的数据 用途
相关值得买内部业务服务 商品链接、SKU/Wiki ID、价格、发布字段、API Key、图片或媒体处理请求。 鉴权、价格查询、历史价判断、爆料发布、赠品解析和媒体处理。
用户访问的受支持网站 由用户在对应网站上提交或操作的数据。 完成商品页面访问、表单填写和用户主动发起的发布操作。
Google Analytics 随机客户端标识、会话标识、版本、功能事件、平台/域名和结果状态等使用数据。 用于内部功能统计、故障分析和稳定性改进。相关处理同时受 Google 隐私权政策约束。

除上述情形外，我们仅会在法律法规要求、保护用户或系统安全，或者服务运营主体发生变更并依法取得必要同意时披露数据。

六、浏览器权限说明

  • storage：保存设置、任务进度、任务历史和授权配置。
  • tabs / activeTab / scripting：在用户使用功能时识别、打开或操作受支持的商品页和爆料页。
  • alarms：执行任务超时、轮询和购物车监控计划。
  • sidePanel：展示任务状态和辅助操作界面。
  • system.display：在多显示器环境中合理定位扩展操作窗口。
  • cookies：读取和管理内部 Superset 服务的登录会话 Cookie，用于维持登录状态并执行用户启用的查询功能。
  • clipboardRead（可选）：仅在用户点击剪贴板导入功能时读取并提取链接。
  • 网站访问权限：在京东、天猫、什么值得买、飞书及提供必要内部能力的服务域名上执行用户可见功能。

七、用户选择、访问与删除

  • 用户可以不授予可选的剪贴板读取权限，并改为手动粘贴链接。
  • 如用户不希望继续产生新的使用统计，可以停用或卸载扩展，也可以通过本政策所列邮箱联系我们。
  • 用户可以清除任务历史和相关本地数据，或者通过浏览器卸载扩展并删除扩展数据。
  • 如需查询、更正或删除可能由内部业务服务保留的数据，可以通过本政策所列联系方式提出申请。

八、数据安全

我们采取合理的技术和组织措施保护数据，包括限制扩展权限、限制内部服务访问、使用身份验证、控制数据保留范围，并持续提升数据传输安全。用户应妥善保管 API Key，不应将其分享给无关人员。

九、Chrome Web Store 有限使用承诺

我们对从 Chrome API 获得的信息的使用将遵守 Chrome Web Store 用户数据政策，包括其 Limited Use（有限使用）要求。

The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.

具体而言，我们仅为提供或改进本扩展已明确说明的单一用途使用相关数据；不会将数据用于个性化广告，不会出售给第三方，也不会允许人工读取用户数据，除非用户对特定数据给予明确同意、为安全调查所必需、为遵守法律所必需，或数据已经聚合和匿名化并仅用于合规的内部运营。

十、政策更新

当扩展功能、数据处理方式或适用规则发生变化时，我们可能更新本政策，并在页面顶部更新生效日期。若变化会显著影响用户数据处理，我们将在收集或使用相关数据前，通过扩展界面向用户进行显著提示，并在需要时重新取得同意。
